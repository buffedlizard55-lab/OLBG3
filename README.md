# OLBG3 — Reverse-engineered match board, own lines &amp; picks

A verified, source-linked dataset built from OLBG.com fixture pages for every in-scope sport (everything **except** soccer/football, American football, boxing/UFC/MMA, hurling, horse racing, cycling and specials), with our own originated prices, handicaps, totals, match-winner picks, confidence labels and written predictions.

- **Live site:** https://buffedlizard55-lab.github.io/OLBG3/
- **Method &amp; scope:** `docs/scope.md`, `docs/method.md`
- **Row-by-row verification:** `docs/verification.md`
- **Coordination board:** `COORDINATION.md`

Every published value carries a source link. Where a value could not be confirmed against an official source it is left blank and listed on the site's *Flagged for Review* page.

> Prices, handicaps and totals are **our own model output** (see `docs/method.md`), not facts and not copied bookmaker prices.
