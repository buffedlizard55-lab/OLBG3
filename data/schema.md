# Data schema

| File | Contents |
|---|---|
| `data/meta.json` | Run metadata, included/excluded sports taxonomy, ambiguity notes, harvest method. |
| `data/raw/olbg-harvest-20261021.tsv` | The raw transcription of every OLBG row captured, one line each, with the exact URL parts. This is the audit trail. |
| `data/matches.json` | Parsed fixtures. Generated by `tools/build_dataset.py` from the TSV plus `data/verifications.json`. |
| `data/verifications.json` | Source register (official / primary / secondary) and per-event verification records with the exact claim each source supports. |
| `data/excluded.json` | Rows belonging to excluded sports, kept as evidence that they were seen and excluded on purpose. |
| `data/lines.json` | Our originated lines: probability, pick, price, handicap, total, confidence, flags. Generated by `tools/originate.py`. |
| `data/predictions.json` | Long-form predictions for high-confidence picks, each with its sources. |
| `data/flagged.json` | Flagged-for-review register. |

## `matches.json` fields

| Field | Meaning | If unknown |
|---|---|---|
| `id` | `<SPORT>-<OLBG event id>` | never blank |
| `sport` | One of the 15 included sports | never blank |
| `olbg_sport_id` | Sport id used in the OLBG URL | never blank |
| `competition` | Competition name | `null`, `competition_status = not_stated_by_source` |
| `competition_status` | `verified` or `not_stated_by_source` | never blank |
| `venue`, `verified_start` | Only set when an official/primary source states it | `null` |
| `event_name` | OLBG's own fixture name, verbatim | never blank |
| `home`, `away` | Mechanical split of `event_name` | `null` for non-head-to-head rows |
| `olbg_date_label`, `olbg_time_label` | Exactly what OLBG printed, no timezone added | never blank |
| `date_iso` | `Today`/`Tomorrow`/`D Mon` resolved against the retrieval date | `null` if unparseable |
| `olbg_market` | The market OLBG highlighted | `null` if OLBG printed none |
| `market_family` | `match_winner`, `other`, `outright` | never blank |
| `olbg_consensus_selection` | OLBG's most-tipped selection, verbatim | `null` |
| `olbg_tips`, `olbg_tips_won`, `olbg_tips_total` | Tip count as printed, plus parsed integers | `null` when truncated |
| `olbg_confidence_pct` | OLBG's percentage, as printed | `null` when truncated |
| `olbg_url` | Exact page the row came from | never blank |
| `fetched_at` | Retrieval timestamp | never blank |
| `verification_ids` | IDs in `data/verifications.json` | `[]` |
| `ambiguous_exclusion` | `true` for Gaelic football (see FL-001) | boolean |
| `row_notes` | Transcriber note | `null` |

## `lines.json` fields

`our_match_probability` is the probability of the **OLBG consensus selection**, not of the
pick, so it can be below 0.5 when the home edge flips the pick. `our_pick_probability` and
the prices always refer to `our_pick`. `flags` is a machine-readable list; every flag has a
matching explanation in `data/model.md` or `data/flagged.json`.

## Verification rule

A value is written only when a cited source states it. Empty stays empty. No value is
derived from another row, from a team's name, or from expectation.
