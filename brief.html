Brief coverage: 16 of 75 targeted picks

The brief asks for the five highest-confidence picks for every covered sport, every day, on matches inside the -250 to +10000 US-odds band (decimal 1.40–101.00), each with a written prediction of at least 30 words. This page counts what is actually published against that target, per sport, and states the mechanical reason each sport falls short. It is an accounting of the committed board, not a promise that five exist.

Rows can fail more than one test, so the counts overlap and are not meant to add up.

What would raise the count

Only two things can, and neither can be done by relabelling a row:

  • A new dated official observation for a fixture whose start is still ahead of the publication clock, with the competition naming the fixture and an explicit timezone on the clock. That is what unlocks the release gate.
  • Official current-form data for both sides on a sport that currently has none, so the model can earn the third evidence point instead of being capped at MEDIUM.

Both require outbound access to the competitions' own sites. That access is blocked in this environment (FL-077), so the honest position today is the 59-pick shortfall shown above — published rather than papered over.
