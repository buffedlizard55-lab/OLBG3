## 3. Four pins that had become clocks (FL-202)

3. `tests/test_audit_beb7787b.py` compared the live HIGH set with "the 23 October candidates that are
   still eligible", which fails the moment a later session adds a legitimate pick. It now grades the

`tests/test_audit_a30d9bdb.py` pins this session's own facts: batch rows are on the board and point at

## 4. The real defect: `verify_live.py` erased provenance (FL-207)

Found while chasing a whole-file diff. `scripts/verify_live.py` wrote

```python
rc['session'] = 'session-22dbc477 (live 2026-10-23 probe)'
vpath.write_text(json.dumps(ver, indent=1) + '\n')
```

so every later probe replaced the provenance header with one fixed string — today's pass deleted the
record of session-b322f52e's F1/URC/EHF reads and session-784afe97's Top 14 holds — and re-encoded
every non-ASCII character in the file, turning a one-field re-observation into a 350-line diff.

Repair: `_append_session()` adds a dated note exactly once and never removes an earlier one, and both
files are written with `ensure_ascii=False`. Session provenance for the 2026-10-24 probes is restored
on the record.
