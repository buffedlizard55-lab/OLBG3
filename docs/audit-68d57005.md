## 2. Root cause (verified from the rows, not guessed)

`data/events.json` row **BKB-17** — *HOU Rockets @ SA Spurs*, NBA Regular Season 2026-27, OLBG event `534841`:

- `start`: `23 Oct 21:40` (OLBG printed label, verbatim); official verification cites the NBA.com schedule: `Fri 23 Oct 2026, 9:30 PM ET, Moody Center, Austin (Prime Video)` — observed 2026-10-23T17:04Z.

- `test_audit_ebe6dc9c.py`'s scan skips rows whose release status is not `upcoming`, so BKB-17 correctly drops out of the candidate list — **the pipeline behaved exactly as designed**. What failed was the pin's *strict list equality* (`== ["BKB-17", "VOL-26"]`), which encoded a 2026-10-23-evening fact as if it were time-independent. Its own docstring already acknowledged the list is time-varying ("Update the expected list, not the grading rule").
- VOL-26 (*Itas Trentino v Cisterna Volley*, SuperLega Round 2, official start `2026-10-25T16:00:00Z`) remains `upcoming` and still appears in the scan; the same failure mode would have recurred on 25 Oct had only BKB-17 been special-cased.

**Classification:** a test-suite defect (dated live-data pin), not a data defect. No fixture, price, grade or prose was wrong on the board. Registered as **FL-199** (severity medium, status resolved).
